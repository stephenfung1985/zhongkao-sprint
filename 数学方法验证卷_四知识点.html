一、单选题

1. C α 是根 → α²=3α+2；原式 = 3α+2+αβ+3β = 3(α+β)+2+αβ。韦达：α+β=3，αβ=−2，代入 = 9−2+2 = 9。
方法：先用根的等式把 α² 降成一次式，再用韦达定理整体代。
2. C m 是根 → m²−2m−4=0 → m²−2m=4 → 2m²−4m=8 → 8+100 = 108。
方法：不求根，先由方程解出整体式子 m²−2m 的值，再倍率代入。
3. B ①二次项系数 k≠0；②Δ=4−4k>0 → k<1。取交集：k<1 且 k≠0。
方法：含参一元二次方程两个条件——二次项系数≠0 ＋ 判别式条件，一个都不能漏。
4. D D 应为 8+2×(10−3)=8+14=22 元，不是 24。C：y=8+2(x−3)=2x+2（x>3）正确。
方法：分段计价——前 3 km 含在起步价里，超出部分才按每千米计价；"每千米"要看从第几千米起算。

二、填空题

5. k<4 且 k≠3 k≠3；Δ=4−4(k−3)=16−4k>0 → k<4。交集：k<4 且 k≠3。
6. 2027 a²−a=2026 → 2026+1 = 2027。
7. 10 x₁+x₂=4，x₁x₂=3 → x₁²+x₂²=(x₁+x₂)²−2x₁x₂=16−6=10。
8. 25 α²=5α−2；原式=5α−2+5β+αβ=5(α+β)−2+αβ=5×5−2+2=25。

三、解答题

9（1） m ≥ −1/2
Δ = [−2(m+1)]² − 4·1·m² = 4(m+1)² − 4m² = 4(m²+2m+1) − 4m² = 8m+4。
有实数根 → Δ≥0 → 8m+4≥0 → m ≥ −1/2。注意：二次项系数 1≠0，无需额外条件。
9（2） m = −2+2√3
韦达：x₁+x₂=2(m+1)，x₁x₂=m²。
x₁²+x₂² = (x₁+x₂)²−2x₁x₂ = 4(m+1)²−2m² = 20 → 4(m²+2m+1)−2m²=20 → 2m²+8m−16=0 → m²+4m−8=0 → m = −2±2√3。
结合（1）m ≥ −1/2：−2−2√3 ≈ −5.46 舍去，m = −2+2√3。
方法：看到 x₁、x₂ 先写韦达定理；x₁²+x₂² 用 (和)²−2(积) 转化；解出的 m 必须回代范围检验。
10（1）① 0.6 ｜ 2.4 ｜ 2.4 ｜ 1.2
去程速度 = 2.4÷24 = 0.1 km/min → 6 分钟 0.6 km；24 分钟到公园 2.4 km；50 分钟仍在公园（24~60 停留）→ 2.4 km；70 分钟：已返回 10 分钟（60~80 返回），2.4 − 0.12×10 = 1.2 km。
10（1）② 0.12 km/min 2.4 ÷ 20 分钟 = 0.12 km/min。
10（2） y = 0.1x（0≤x≤24）；y = 2.4（24<x≤60）
三段：去程 y=0.1x；公园停留 y=2.4（水平段）；返回 y=2.4−0.12(x−60)=9.6−0.12x。
10（3） y = 9.6 − 0.12x（60<x≤80）；x=65 时 y=1.8 km
x=65 → 9.6 − 0.12×65 = 9.6 − 7.8 = 1.8 km。
方法：分段函数每段先写区间再写解析式；停留段是水平线 y=常数；速度 = 路程 ÷ 时间，算完检查数量级。
