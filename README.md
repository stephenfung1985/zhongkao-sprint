# 中考冲刺复习平台 · 天津滨海新区 · 290 天

## 怎么打开

**双击 `启动学习平台.bat`**（不是 index.html）。

会弹出一个黑色命令行窗口，然后自动打开浏览器。**学习期间不要关那个黑窗口**，
它负责把打卡记录实时存到磁盘；学完之后直接关掉即可。

建议右键 `启动学习平台.bat` → 发送到 → 桌面快捷方式，以后从桌面点。

> ### ⚠ 为什么不能再双击 index.html 了
>
> 之前出现过「打完卡第二天记录就没了」。原因是：直接双击网页文件打开时，
> 浏览器地址是 `file://`，这种页面的数据被浏览器归类为**「本地文件站点数据」**，
> 只要发生下面任何一件事，打卡记录就会被连锅端掉：
>
> - 浏览器设置了「关闭时清除 Cookie 和站点数据」
> - 手动清理了浏览数据
> - **电脑上的清理软件（360、电脑管家等）扫了一遍浏览器痕迹** ← 最常见
>
> 现在改成通过本地服务器打开，学习记录会**实时写进磁盘上的一个真实文件**，
> 浏览器怎么清理都影响不到它。
>
> 页面顶部有一条状态提示：绿色 = 已存到磁盘；红色 = 打开方式不对或服务器没开着。
> **只要看到红色就停下来处理，别接着学。**

- 页面底部的「导出学习数据 / 导入数据」按钮仍然可用，作为额外一层保险

## 试卷深度解析系统（新）

主页面顶部新增「**📄 卷子分析**」按钮，点进去是独立的试卷复盘工作台。
**从现在开始，每考完一套卷子（学校的、自己出的都算），都把做错的题录进去，走完整闭环：**

```
深挖错误原因 → 举一反三变式题 → 逐题确认闭环 → 复盘总结 → 30分钟小卷验证
```

### 具体怎么用

1. **新建试卷分析**：选科目、填标题/日期/来源/成绩。
2. **录入错题**：每题可以「从题库选」（按知识点挑，自动带出答案和解析），
   也可以手动录入。每题都要选**错误原因**——平台按七类深挖：
   概念不清 / 公式方法记错 / 审题失误 / 计算错误 / 方法不会 / 时间不够 / **似懂非懂**。
3. **深挖**：点每题左上角的错因标签，会弹出针对这个错因的自问自答和对策，
   让她先想清楚错在哪，再往下做。
4. **举一反三**：点「举一反三 →」，平台从课程库抽同一知识点（抽不到就同一课、同一科）的
   3 道变式题——**必须全部做对，这道题才能点「确认闭环」**。
   做错任何一道都不许闭环，防止「看答案觉得会，合上就忘」。
5. **复盘总结**：错题闭环有进展后点「生成复盘总结」，看这套卷的错因分布、
   薄弱知识点分布和针对性建议。
6. **30 分钟小卷**：错题**全部闭环后自动解锁**。平台从这套卷的薄弱知识点抽 12-16 道题，
   30 分钟限时，**得分 ≥ 80 分才算这套卷真正闭环**；不到 80 分说明还有似懂非懂，
   回到对应课程重学、重做变式、再测一次。

### 数据说明

- 试卷分析记录和每日冲刺**共用同一份学习数据**（`学习数据/学习记录.json`），
  导出/导入、历史备份、换电脑迁移全部自动带上。
- 小卷里还做错的题**自动进全局错题本**，按艾宾浩斯 1/3/7/15/30 天安排复现，双重保险。

## 每日播客 · 中考三十分钟电台（新）

**每天下午 5 点，电脑会自动做好一期 15 分钟的复习播客，晚饭时候放着听。**

不用手动做任何事。顶部点「**🎧 播客**」进去，最上面那期就是今天的，点播放就行。

### 为什么要有这个

每天 30 分钟是「动手」的时间，注意力很贵，只够攻一个考点。
但吃饭那 15 到 20 分钟本来就是空的 —— 眼睛和手都被占着，耳朵闲着。
这段时间做不了题，但**可以复习**：昨天错的题重新问一遍、到期该复现的错题过一遍、
一条应试技巧、几个单词。全是「听一遍就有用」的东西，不需要她动笔。

而且它还顺便解决了一个问题：**今晚要学的那一课，她在饭桌上就已经听过一遍了。**
播客最后会剧透今晚的核心结论、把苏格拉底第一问先问一遍。
带着问题坐下来学，那 30 分钟的效率完全不一样。

### 一期节目里有什么

节目是双主播对话（晓晓讲、云希问），不是一个人念稿子 —— 一个人念 15 分钟，第 5 分钟就走神了。

| 环节 | 内容 | 素材从哪来 |
|---|---|---|
| 战报 | 第几天、距中考几天、连续打卡、本阶段重点 | `plan-config.js` + 打卡记录 |
| 昨日回放 | 昨天哪一课、核心一句话、费曼展开、她自己写的复盘 | 课程库 + 昨天的打卡 |
| 错题重审 | 昨天错的题，逐道口播 → **留白 6 秒** → 答案 → 陷阱 | 错题本 |
| 到期回炉 | 按艾宾浩斯今天该复现的题 | 错题本的 `nextDue` |
| 英语两分钟 | 当天那组微剂量 + 本周单词听写抽查 | `english-daily.js` + `vocab-week.js` |
| 错题分布 | 错题现在堆在哪一科 | 错题本 |
| 科目战报 | 七科轮换，一天点一科的名，讲现状和眼下该做什么 | `plan-config.js` 的分值表 |
| 应试技巧 | 40 条天津卷专用技巧，一天一条轮换 | `播客/技巧库.js` |
| 今晚预告 | 今晚学什么、结论剧透、苏格拉底第一问、第一道练习题 | 课程库 |
| 收尾 | 一句家里人的话 | `family-messages.js` |

**内容全部来自平台自己的数据**，不是通用鸡汤。她昨天错哪道题，今天播客就讲哪道题。
排课逻辑也直接复用 `js/plan.js`，所以「播客说今晚学什么」和「平台今晚真的排什么」永远是同一个答案。

每道题念完都会**留白几秒**让她在心里答 —— 这是整档节目最有价值的设计。
听答案很轻松，但只有自己先想过，听到答案的那一下才会留下痕迹。

### 页面上能干什么

- **点播放**就行。进度条可以拖，从中间接着听也行。
- 点「**显示文稿**」能看全文；播放的时候当前这句会**自动高亮并滚动**（跟读），
  点任何一句可以直接跳到那一秒。听不清的地方用这个回看。
- 点「**存到手机**」把 mp3 下下来，发到手机上，在车里、路上都能放。
- 往期节目在下面列着，随时回听。

### 自动是怎么跑的

Windows 计划任务，名字叫「**中考播客-每日17点**」，每天 17:00 静默执行
（用 `pythonw` 跑，不弹黑窗口，不打扰做饭）。

- **那会儿电脑关着怎么办？** 任务设了「错过了就在下次开机后补跑」，开机自动补。
- **要改时间？** 开「任务计划程序」找到这个任务改触发器；
  或者命令行跑一句：`schtasks /Change /TN "中考播客-每日17点" /ST 18:30`
- **想立刻做一期？** 双击 `立即制作今天的播客.bat`。
- **哪天没出播客？** 看 `播客/日志.txt`，每次运行都有记录，卡在哪一步写得很清楚。

**合成需要联网**（用的是微软 Edge 的免费语音，不要账号不要 key），一期大约 3-8 分钟。
合成完就是本地 mp3，播放不需要网。断网那天会在日志里说清楚，联网后双击那个 bat 补做即可。

### 每天 30 分钟怎么花

```

STEP 2  苏格拉底对话  8 分钟   ← 不给答案，只给下一个问题
```

### 三轮螺旋

同一个考点会在 290 天里遇到三次，每次形式不同：

- **第 1 轮 learn**：完整苏格拉底对话 + 基础题（慢，求懂）
- **第 2 轮 drill**：不再重讲，直接上题，错了才回看讲解
- **第 3 轮 flash**：只做这个考点最容易错的 2-3 题，5 分钟解决

这正好对应中考的一轮 / 二轮 / 三轮复习节奏，不需要手动切换，平台按日期自动判断。

## 苏格拉底教学法在这里是怎么做的

不是"讲一遍然后做题"，而是**答错时不给答案，只给下一个问题**。

举个真实的例子（数学第 1 课）：

> **问：** `-3²` 等于多少？
>
> 她选「9」→ 平台不说"错了，应该是 -9"，而是反问：
>
> > 如果答案是 9，说明你把平方号盖在了「-3」整体上。可是式子里，
> > 3 的前面有括号吗？没有括号的时候，平方号只够得着紧挨着它的那个数。
>
> 选项还在，她可以重选。连错 3 次，才给一个台阶（rescue）：
>
> > 把 -3² 补全成 `-(3²)`，你就看清了：先算 3²=9，再取负 → -9。

答对了才给结论（close），然后进入下一轮提问。一课 3-4 轮，层层递进。

练习题答错后还有一个「**我还是没懂**」按钮，点了会把这道题拆到最小一步，
并且明确告诉她：如果这一步还卡，说明卡的不是这道题，是它前面那个知识点。

## 错题本是自动的

- 做错的题**自动进错题本**，不用手动记
- 按**艾宾浩斯间隔 1 / 3 / 7 / 15 / 30 天**自动排复现
- 复现的题会插在第二天的练习最前面（周日复盘日一次插 6 道）
- 同一道题连对 5 次才算"攻克"；中途再错一次，进度倒退一级
- 数据看板里有「**错题堆在哪一科**」的图 —— 这张图最有价值，
  正确率会因题目难度波动，但错题堆积的方向不会骗人

## 一周背单词计划 + 奖励机制（新）

顶部第三个页签「**背单词**」。和每天 30 分钟的主流程互不干扰，单独一块，约 10 分钟。

### 计划怎么排的

英语是全卷最大的坑（120 分只拿 65.5）。单词靠**见面次数**，不靠单次时长 ——
所以不是「一天背 50 个」，而是：

| | 内容 | 说明 |
|---|---|---|
| 周一 ~ 周六 | 每天 16 个新词 | 先翻词卡认脸（点卡片看意思、点 🔊 听发音），再闯关 |
| 周日 | 不学新词 | 全周 96 词随机抽 30 道，三种题型混考，结算本周奖励 |

**一周 96 词，下周还是这 96 个词，但考法升一级：**

1. **第 1 轮 · 认脸** —— 英译中为主，只要求认出来
2. **第 2 轮 · 会拼** —— 中译英拼写为主，给首字母提示
3. **第 3 轮 · 盲拼** —— 例句挖空为主，不给提示

一周结束拿到 12 星以上才升级考法；没到就把同一轮再刷一遍。
**同样 96 个词，一个月里会被拷问四次，一次比一次严** —— 这就是间隔重复。

96 个词按六天分组：高频动词（拼错就丢分的那一批）、形容词副词（作文的血肉）、
名词（可数不可数是主战场）、连词与介词短语（句子的胶水）、动词短语（阅读的拦路虎）、
话题词汇（环保 / 健康 / 科技，作文高频）。每个词都带例句和**中考易错点**，
不是光给中文意思。答错的词按艾宾浩斯 1 / 2 / 4 / 7 / 15 天自动排回炉，插在后面几天的闯关里。

### 奖励机制的三条设计原则

1. **只加分，不扣分。** 答错不减词力值，只让这个词更快回来找你。
   目的是让她愿意点开，而不是怕点开。
2. **星星按「今天有没有做」给，不按「聪明不聪明」给。**
   做完 = ★1，正确率 ≥ 80% = ★2，全对且回炉旧词也全清 = ★3。一周满分 21 星。
3. **断一天不清零。** 这一周里任何一个过去的日子都能点进去补做，
   但补做最多 2 星 —— 补得回损失，补不回「当天就做」那一颗。代价温和，但真实。

具体的奖励有四层，从即时到延迟：

| 层 | 是什么 | 触发 |
|---|---|---|
| 即时 | 词力值 | 答对 +2；这个词第一次答对再 +1；连对 3 个以上每题再 +1（连击）；完成一天 +5；满星日 +10；周日闯关达标 +50 |
| 当天 | 星星 | 每天最多 3 星，首页七天格子一眼看完这周的坑 |
| 长期 | 段位 | 词汇新兵 → 学徒 → 匠人 → 达人 → 宗师（0 / 300 / 800 / 1600 / 2800 分） |
| 收藏 | 徽章 | 10 枚：开张大吉、满星日、连击王、零失误、清账人、七日不断、周冠军、二周目、盲拼者、词汇宗师 |

### 家长要做的一件事

首页「奖励中心」下面有「**家长设置：改这三档奖励**」，默认是 12★ / 16★ / 19★ 三档，
文案可以自己改成她真正想要的东西（默认写的是「周末多一小时自由时间」这类）。
兑换记录跟着学习数据一起存盘，赖不掉，也不会丢。

> 提醒：奖励要她真的想要，否则星星就只是星星。
> 小奖当周兑现，大奖提前说好是什么 —— **说话算数比奖励本身管用**。

## 给家长的四句话

1. **连续比强度重要。** 断一天不要紧，别断两天。平台首页的连续打卡数就是给这个用的。

2. **别看正确率，看「错题堆在哪一科」那张图。** 每月底看一次，
   把最高的那一科在下个月加一天（改 `data/plan-config.js` 里的 `rotation`）。

3. **改完文件后直接刷新页面就生效**，不需要改版本号——服务器已经设置成不缓存。

4. **费曼那一栏她写不出来，说明今天没懂。** 这比做对几道题更能反映真实情况。
   写不出来不用批评，记下来第二天让平台重排这个考点就行 —— 它本来就会重排。
