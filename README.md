## 页面顶部的两个东西

### 家人寄语

标题下面那张卡片，是**家里人写给冯子妤（小鱼）的话**，共 48 句：

| 谁 | 几句 |
|---|---|
| 爸爸 | 14 |
| 妈妈 | 14 |
| 弟弟 | 14 |
| 吾悦（狗子）| 6 |

- **每次打开首页自动换一句**，48 句全部转完才会从头开始
- **四个人轮流出场**：爸爸 → 妈妈 → 弟弟 → 吾悦 → 爸爸 → …
  文件里是按人分组存的（方便编辑），但展示时程序会自动重排，
  所以**不会连着看到同一个人说好几条**。吾悦的 6 句说完后，自动跳过它继续三人轮
- 卡片**点一下就换下一句**，想多看几句随时点
- 要增删改，打开 `data/family-messages.js`，在对应分组里加一行：
  `{ from:"爸爸", text:"..." },`
  加多少都可以，加完程序会自动把它排进轮换里。**记得每句带上对她的称呼**（小鱼 / 子妤 / 冯子妤）

### 亮色 / 暗色切换

右上角那个图标按钮。**亮色时显示月亮**（点了变暗），**暗色时显示太阳**（点了变亮）。

- 没手动点过时**跟随系统设置**，系统换主题它会实时跟着换
- 手动点过之后就以手动选择为准，记在本地，下次打开还是这个
- 晚上写作业建议用暗色，白天用亮色

### 语音讲解

苏格拉底对话和练习题解析都支持**语音朗读**，用的是浏览器自带的语音合成（不需要联网、不需要音频文件）。

- 进入 STEP 2 苏格拉底对话后，右上角有「🔊 语音讲解」按钮，点一下切换开/关
- 开启后：每轮提问自动朗读、答对后的确认和结论自动朗读、答错的提示自动朗读、连错3次的台阶自动朗读
- 练习题答错后，解析会自动朗读；答对时可以点解析旁边的 🔊 小按钮手动朗读
- 朗读时当前气泡会有高亮边框和 🔊 标记
- 开关状态会记住，下次打开还是上次的选择
- 语速设为 0.92（稍慢），适合听讲；如果系统没有中文语音包，会自动用默认语音

### 每天 30 分钟怎么花

```
STEP 1  英语微剂量    5 分钟   ← 每天都做（周二除外，那天整块攻英语）
STEP 2  苏格拉底对话  8 分钟   ← 不给答案，只给下一个问题
STEP 3  精准练习     13 分钟   ← 中考真题改编，5-6 道，基础题为主
STEP 4  复盘打卡      4 分钟   ← 费曼一句话 + 打卡
```

**知识点 : 练习 ≈ 4 : 6。**
针对"基础薄弱、常错送分题"，讲多了记不住，练多了打击信心。
一天只攻一个考点、只做 5-6 道题。目标是**今天这个点明天不会再错**，不是今天做了多少题。

### 三轮螺旋

同一个考点会在 290 天里遇到三次，每次形式不同：

- **第 1 轮 learn**：完整苏格拉底对话 + 基础题（慢，求懂）
- **第 2 轮 drill**：不再重讲，直接上题，错了才回看讲解
- **第 3 轮 flash**：只做这个考点最容易错的 2-3 题，5 分钟解决

这正好对应中考的一轮 / 二轮 / 三轮复习节奏，不需要手动切换，平台按日期自动判断。

## 苏格拉底教学法在这里是怎么做的

不是"讲一遍然后做题"，而是**答错时不给答案，只给下一个问题**。

举个真实的例子（数学第 1 课）：

> **问：** `-3²` 等于多少？
>
> 她选「9」→ 平台不说"错了，应该是 -9"，而是反问：
>
> > 如果答案是 9，说明你把平方号盖在了「-3」整体上。可是式子里，
> > 3 的前面有括号吗？没有括号的时候，平方号只够得着紧挨着它的那个数。
>
> 选项还在，她可以重选。连错 3 次，才给一个台阶（rescue）：
>
> > 把 -3² 补全成 `-(3²)`，你就看清了：先算 3²=9，再取负 → -9。

答对了才给结论（close），然后进入下一轮提问。一课 3-4 轮，层层递进。

练习题答错后还有一个「**我还是没懂**」按钮，点了会把这道题拆到最小一步，
并且明确告诉她：如果这一步还卡，说明卡的不是这道题，是它前面那个知识点。

## 错题本是自动的

- 做错的题**自动进错题本**，不用手动记
- 按**艾宾浩斯间隔 1 / 3 / 7 / 15 / 30 天**自动排复现
- 复现的题会插在第二天的练习最前面（周日复盘日一次插 6 道）
- 同一道题连对 5 次才算"攻克"；中途再错一次，进度倒退一级
- 数据看板里有「**错题堆在哪一科**」的图 —— 这张图最有价值，
  正确率会因题目难度波动，但错题堆积的方向不会骗人

## 关于题目来源（重要，请如实告知）

平台里的题是**按天津卷近三年（2023–2025）的题型结构、考点分布和难度梯度编写的仿真题**，
每题都标了来源类型（真题改编 / 真题同源 / 高频考点）。

**这些不是逐字的真题原文** —— 考点和陷阱是真的，题面是重写的。我没有真题数据库可以逐字检索。

**建议**：到 2027 年 3 月一轮复习时，另外买一本天津中考真题卷做整套限时训练。
平台负责补基础和抓错题，真题卷负责练手感和时间分配，两者不冲突。

## 给家长的四句话

1. **连续比强度重要。** 断一天不要紧，别断两天。平台首页的连续打卡数就是给这个用的。

2. **别看正确率，看「错题堆在哪一科」那张图。** 每月底看一次，
   把最高的那一科在下个月加一天（改 `data/plan-config.js` 里的 `rotation`）。

3. **改完文件后如果页面没变化**，是浏览器缓存。把 `index.html` 里所有 `?v=20260903d`
   改成一个新的值（比如 `?v=20260904a`）再刷新就行。

4. **费曼那一栏她写不出来，说明今天没懂。** 这比做对几道题更能反映真实情况。
   写不出来不用批评，记下来第二天让平台重排这个考点就行 —— 它本来就会重排。
